# Визуализатор алгоритмов поиска пути (Python 3.10 + Tkinter)

Запуск программы:        python main.py
Тесты алгоритмов:        python test_algorithms.py
Сравнение алгоритмов:    python benchmark.py   (создаёт results.csv)

Устанавливать ничего не нужно: используется только стандартная библиотека Python.

Файлы:
- grid.py        — модель сетки (клетки, стены, болото, соседи, генераторы карт)
- algorithms.py  — BFS, Дейкстра, A* (общий класс PathFinder, пошаговое выполнение)
- gui.py         — интерфейс Tkinter (редактор карты, анимация, статистика, сравнение)
- main.py        — точка входа
- benchmark.py   — сравнительный анализ на разных типах карт
- test_algorithms.py — автотесты

Управление: ЛКМ — рисовать выбранным инструментом, ПКМ — стереть,
старт и финиш можно перетаскивать мышью.
