# Визуализатор алгоритмов поиска пути (Python 3.10 + Tkinter)

Запуск программы:   python main.py

Файлы:
-  grid.py        - модель сетки (размер, стены, старт, финиш, соседние клетки)
- algorithms.py  - BFS, Дейкстра, A* (общий класс PathFinder, метод step())
- gui.py         - интерфейс Tkinter
- main.py        - звпуск программы
